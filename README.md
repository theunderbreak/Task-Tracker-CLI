# Task Tracker CLI

A simple console application for task tracking.

## Commands

- `python tasktracker.py add "Buy groceries"` — add tast
- `python tasktracker.py list` — show all tasks
- `python tasktracker.py list done` — show done tasks
- `python tasktracker.py update 1 "New description"` — edit description
- `python tasktracker.py delete 1` — delete task
- `python tasktracker.py mark-done 1` — mark done
- `python tasktracker.py mark-in-progress 1` — mark in progress

## Start

```bash
python tasktracker.py --help
